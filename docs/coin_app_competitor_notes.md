# CoinScan Competitor Notes

Research date: 2026-08-26

## Five App Store competitors reviewed

1. CoinSnap: Coin Identifier
   - Positioning: AI coin recognition, large global database, coin value, grading, collection management.
   - Public claim to watch: 300,000+ coin types and 99% recognition accuracy.
   - Opportunity: CoinScan can feel more trustworthy by showing evidence, uncertainty and source quality instead of only a final answer.

2. Coinoscope: visual coin search
   - Positioning: visual search for similar coins, issue year/details, collection management, free basic use with Pro/ad removal.
   - Strength: broad world-coin discovery and possible-match behavior.
   - Opportunity: CoinScan should preserve possible matches when confidence is low, then ask for reverse/edge photos to resolve ambiguity.

3. AI CoinScan: Coin ID & Value
   - Positioning: identify, categorize and manage a coin collection with improved AI speed and a modern interface.
   - Opportunity: The name space is crowded. CoinScan needs a distinctive trust layer, not just another "AI value" wrapper.

4. Coin ID Scanner: Value Checker
   - Positioning: instant identification, value checker, specifications and collection management.
   - Opportunity: Beat it with a calmer, more professional scanner and clearer separation of face value, metal value, collector value and market estimate.

5. Coin ID: Coin Value Identifier
   - Positioning: quick photo ID, world coin details, size/composition/origin and collection tracking.
   - Opportunity: Go deeper on historical context, evidence explanations, privacy, exportable reports and international currency preferences.

## Product direction

CoinScan should not promise that it detects every coin ever made. It should aim for worldwide recognition while being honest about confidence, unavailable data and valuation limits.

The strongest differentiators:

- Two-sided scanning by default: front, reverse, optional edge.
- Evidence panel: OCR, year, country, denomination, mint mark, design match and physical specification cues.
- Low-confidence flow: show possible matches and practical retake guidance.
- Valuation architecture: separate face value, metal value, collector value and market estimate.
- Trust language: never claim a coin is authentic from a normal phone photo.
- Privacy: explain image storage, upload, retention and scan-history deletion.
- Worldwide settings: preferred currency, locale-aware formatting and no India-only assumptions.
